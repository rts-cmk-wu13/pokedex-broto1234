# Pokédex
A responsive and dynamic website created with HTML, CSS, and JavaScript.

## Features
🔍 Search Pokémon by name or number. By clicking on the link, the user should be shown a new page (e.g. `detail.html`)

📦 Fetch data from the PokéAPI (https://pokeapi.co/) using Fetch API

💡 Displays Pokémon image, name, and ID

📱 Mobile-friendly and responsive design

## Live Demo
Check out the live website here: [On netlify](https://my-project-pokedex.netlify.app/)

## Technologies Used
This project was built using the following technologies:
- **HTML5**: Markup structure
- **CSS3**: Styling and layout (including Flexbox and Grid)
- **JavaScript**: Dynamic behavior and interactivity
- **GitHub**: Deploy on GitHub page for static sites
- **Netlify**: Deploy on Netlify
